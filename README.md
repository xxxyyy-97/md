## Введение

**Data Vault 2.0** — методология построения хранилищ данных, которая обеспечивает:
- **Гибкость**: легко добавлять новые источники
- **Историчность**: полная история изменений
- **Аудируемость**: отслеживание происхождения данных
- **Масштабируемость**: работает с большими объемами

**Основные компоненты:**
- **Hub**: бизнес-ключи сущностей
- **Satellite**: атрибуты с историей изменений
- **Link**: связи между сущностями
- **PIT (Point-in-Time)**: снимки состояний на любую дату
